## Shared-main workflow

1. Claim an unowned path in `docs/OWNERSHIP.md` before editing; do not touch
   `uxui/**` or `lib/ocr/**` unless that owner explicitly reassigns it.
2. Fetch and fast-forward only from a clean worktree. Inspect concurrent
   changes before touching shared files.
3. Implement the smallest slice, run its focused checks, then run the relevant
   typecheck/tests/build. Do not stage another agent's work.
4. Inspect the staged diff and scan for secrets; make one small atomic commit
   and push it normally to `main` (never force-push or rewrite shared history).
5. Mark the slice here with its commit/evidence, dependency state, and next
   blocker so the next agent can pick it up safely.
